EASY STAY LOGO KIT

Primary: stacked symbol and wordmark for covers and signage.
Horizontal: symbol beside wordmark for website headers and email signatures.
Icon: standalone symbol for compact uses; icon-tile is the teal rounded-square social version.

SVG files are scalable vector masters. All wordmark lettering is outlined and requires no font installation.
PNG logo exports have transparent backgrounds. The icon-tile has a teal background with transparent outer corners.
Colour, solid teal and solid white versions are included. White versions need a dark background.
Small icon exports: 32, 64, 180 and 512 pixels.

Colours: deep teal #174C46; apricot #F2B38A; warm canvas #FAF7F0.
Keep clear space at least equal to the door-leaf width around each logo. Do not stretch, rotate or add shadows.
Use the standalone icon when the full name would become too small to read.
The preview board is a presentation image, not a transparent logo asset.

Created as vector artwork from the Easy Stay Open Door concept. Wordmark derived from Segoe UI Bold outlines.
